# 3D Models Repository

A growing collection of 3D models, prototypes, and experiments created over time. This repository is intended to hold the models I build and refine as I learn, design, and iterate on different ideas.

## Overview

This project serves as a personal archive for 3D work, including:

- Concept models and exploratory designs
- Printable objects and functional parts
- Decorative or artistic pieces
- Reusable components and study models
- WIP ideas that may evolve into finished projects

The aim is to keep things organized, easy to browse, and ready for future iteration or export to common 3D formats.

## Repository Structure

A typical layout keeps each model's files together in its own folder:

```text
3d/
├── README.md
├── models/
│   ├── model-name/
│   │   ├── model-name.scad
│   │   │   ├── exports/
│   │   │   │   └── model-name.stl
│   │   │   ├── renders/
│   │   │   │   └── model-name.png
│   │   └── README.md
│   ├── another-model/
│   │   ├── another-model.scad
│   │   │   ├── exports/
│   │   │   │   └── another-model.stl
│   │   │   ├── renders/
│   │   │   │   └── another-model.png
│   │   └── README.md
...
```

Keep each model's native design files, exports, previews, and notes in its folder. Organize models by project within `models/` if the collection grows.

## Supported Formats

This repository may contain files in formats such as:

- OpenSCAD source
- STL
- STEP / STP
- Autodesk® Fusion archive and design files (F3D, F3Z)

The exact formats will depend on the model and its intended use.
